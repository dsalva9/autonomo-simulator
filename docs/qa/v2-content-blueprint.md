### Mandatory Wave 3 Authoring & Validator Contracts (Synchronized with ADR 004)
1. **Strict Zero-Collision File Ownership**:
   - `content-fixer`: edits **only existing** 300 files in `content/events/*/*.yaml` and existing 5 shards `content/locales/en/{clientes,empleados,familia,gestor,hacienda}.yaml`.
   - `content-writer-life`: creates **only new** files in `content/events/familia/*.yaml` (15) and `content/events/hacienda/*.yaml` (10), plus **new** shard `content/locales/en/v2_life_and_long_arcs.yaml`.
   - `content-writer-scale`: creates **only new** files in `content/events/clientes/*.yaml` (18), `content/events/empleados/*.yaml` (11), and `content/events/gestor/*.yaml` (8), plus **new** shard `content/locales/en/v2_scale_and_agency.yaml`.
2. **Naming & Schema Contracts**:
   - Every event ID MUST be Spanish `snake_case` starting with `<category>_` (`clientes_`, `empleados_`, `familia_`, `gestor_`, `hacienda_`) and match its filename stem.
   - Anti-softlock invariant: **every event MUST keep `>= 2` choices and `>= 1` completely unconditional choice** (remember ADR 004 §6.1: `business_tiers`, `team_size`, and `children_count` count as active requirements in `hasActiveRequirements()`).
   - **Opt-In `scale_with_tier: true` Guard**: Only use `scale_with_tier: true` on events whose `title`, `body`, and `choices[].label` contain **zero literal `€` symbols** (enforced by `scripts/validate-content.ts`). All bespoke tier-gated S.L./Agency events with explicit Euro figures MUST omit `scale_with_tier` (`false`).
   - **Valid `character_expression` Matrix** (enforced by `tests/content/content.test.ts`):
     - `cliente_corporativo_marta`: `neutral | angry`
     - `empleada_senior_laura`: `neutral | stressed`
     - `cliente_regateador`, `hacienda_inspector_gomez`: `neutral | angry | pleased`
     - `gestor_barato_paco`, `gestor_premium_elena`, `pareja_alex`, `empleado_junior_dani`: `neutral | stressed | pleased`
   - **Partner Name Placeholder**: Always write `Álex` in Spanish YAML and `Alex` in English YAML so `substitutePartnerName()` dynamically injects the seeded run partner name (`Álex | Cris | Gabi | Noa | Clara`).
   - **Zero-Scroll Copy Budget**: Keep `title <= 72` chars, `body <= 255` chars, `choice.label <= 85` chars, and prefer **3 choices** (cap at **4 choices** only where explicitly noted) so `360×780`, `390×844`, `1366×768`, and `1440×900` remain 100% zero-scroll.
   - **Contextual Weight Tags (ADR 004 §5.2)**:
     - Partner crisis events (`2.8x / 4.5x` boost at `personal_life <= 38 / <= 25`): include `crisis_pareja` or `pareja_ultimatum`.
     - Partner upside events (`2.0x` boost at `personal_life >= 70`): include `sinergia_pareja` or `red_pareja`.
     - 4-year *prescripción fiscal* historical audit pool (ADR 004 §4.2): include `prescripcion_fiscal`.
   - **Modifier & Flag i18n Handoff**: Wave 3 workers MUST report every newly introduced `add_modifier` (`id` + `es-ES` label + `en` label) and new flag ID to Wave 4 (`sim-balancer`) for registration in `MODIFIER_LABELS_BY_ID_EN`, `MODIFIER_LABELS_EN`, and `FLAG_LABELS` inside `src/services/i18n/resolveEventText.ts`.
   - **Late-Game Repeatable Invariant (`tests/content/content.test.ts`)**: Keep `>= 25` random events (`weight > 0`) with `min_month >= 60` and `max_occurrences: null`, preserving `clientes_renovacion_cartera_veterana`, `clientes_acuerdo_marco_multianual_ibex`, `familia_sabatico_largo_veterano`, and `empleados_paga_aniversario_estudio`.
